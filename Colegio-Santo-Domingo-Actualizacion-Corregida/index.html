¿Necesitas ayuda?

Consulta aquí información importante para estudiantes y padres de familia. Empezamos con el proceso de pago de mensualidades.

Pago de mensualidad Banco Industrial / Agente Bi

Realiza el pago utilizando el código estudiantil asignado por el colegio.

Dato para realizar el pago 5689 + CÓDIGO DE ESTUDIANTE El signo “+” indica que debes proporcionar ambos datos: el convenio 5689 y tu código estudiantil.
1
Tu identificación de pago

Recibe tu código único estudiantil

Dirección asignará a cada estudiante un código único. Guárdalo, porque este dato identifica a quién corresponde la mensualidad.

2
Acude a un punto de pago

Ve a Banco Industrial o a un Agente Bi

Puedes dirigirte a Banco Industrial o a un Agente Bi disponible. Lleva contigo el código estudiantil para evitar errores al momento de efectuar el pago.

3
Indica los datos correctos

Proporciona el convenio 5689 y tu código

Al realizar el pago, indica el número de convenio 5689 y después proporciona tu código de estudiante. Verifica ambos datos antes de finalizar la operación.

4
Comprobante de pago

Guarda tu voucher

Al terminar, recibirás un comprobante o voucher. No lo deseches. Guárdalo durante el ciclo escolar como respaldo de tu pago.

Pago desde el teléfono

También puedes pagar desde Bi Móvil

Si utilizas la aplicación de Banco Industrial, realiza el pago desde el apartado de servicios y verifica cuidadosamente los datos antes de confirmar.

1
Ingresa a Pagos

Abre Bi Móvil y entra al apartado Pagos.

2
Selecciona Servicios

Dentro de Pagos, selecciona Servicios.

3
Coloca el convenio 5689

Ingresa el convenio 5689 y proporciona el código único del estudiante cuando el sistema lo solicite.

4
Verifica los datos

Comprueba que la información corresponda al estudiante y que el monto sea correcto.

5
Realiza el pago y guarda el voucher

Confirma la operación y guarda el comprobante digital. Dirección puede solicitarlo para verificar la mensualidad.
